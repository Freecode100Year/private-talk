Private Talk 游戏平台 · 可交互原型

分支 feat/game-platform · 第二步 · 只是原型：数据是演示用的，没有连接任何服务器。设计说明见 docs/design/game-platform.md。

① 首页（桌面版）
在电脑上打开：快速找一桌 / 私密房间两个入口、等人中的公开桌（可切换「有人等 / 空 / 大厅不可用」）、游戏卡片（人数、时长、等待人数）。 ② 首页（手机版）
同一个页面，在手机上（或把窗口拉窄到 820 像素以下）自动变成手机布局：按钮上下排、游戏两列、弹出的选择面板从底部出来。 ③ 游戏围桌（狼人杀 9 人）
手机：底部「桌子 / 聊天 / 房间」三个标签；电脑：三栏。可以点座位选目标、看身份牌、发快捷表情、切换夜晚 / 发言 / 投票 / 结束、模拟掉线后 80% 投票补位、友善离桌、再来一局。
