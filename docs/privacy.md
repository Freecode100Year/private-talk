# 隐私与安全设计

[README](../README.md) 里是简要版。这里逐项写清楚每一层怎么做、能防什么、防不了什么。

## 谁能看到什么

| | 服务器运营方 | 网络上的旁观者（运营商、Wi-Fi 管理者） | 房间里的其他人 |
| :--- | :--- | :--- | :--- |
| 消息内容 | 看不到（只有密文） | 看不到（HTTPS + 端对端加密） | 看得到 |
| 暗号 | 看不到（只在浏览器里用） | 看不到 | 知道 |
| 你是谁 | 不知道（无账号、无昵称） | 不知道 | 只看到编号 1️⃣～🔟 |
| 你的 IP 和上线时间 | 看得到 | 看得到你连了这个网站 | 看不到 |
| 哪些连接在同一个房间 | 看得到（但不知道房间里在说什么） | 看不到 | 看得到人数 |

## 逐项说明

| | 做法 |
| :--- | :--- |
| 暗号 | 默认随机生成。只在浏览器里用：放在链接 `#` 后面，浏览器不会把它发给服务器；进入房间后立即从地址栏抹掉；页面上只显示 4 位房间代号（如“房间 7F3A”），截图不会泄露暗号 |
| 房间地址 | 由暗号经 PBKDF2-SHA256（31 万次）算出的 64 位十六进制，服务器无法反推暗号 |
| 消息 | 浏览器用暗号派生的 AES-256-GCM 密钥加密；服务器只转发密文，没有密钥 |
| 防篡改 | 发送人编号、消息编号和发送时间都封在密文里。浏览器核对服务器标注的发送人，按本机时间拒绝超过 10 分钟的消息，并拒绝本页面已经见过的消息编号。这能防止服务器出错或被篡改时改动发送人、重放旧消息。**做不到的**：知道暗号的成员如果和服务器串通，可以冒充别人（所有人共用一把钥匙）；10 分钟内的消息对新打开的页面仍可能被重放 |
| 历史 | 不存储。服务器（Cloudflare Durable Object）只在内存里转发；新加入的人看不到之前的消息 |
| 身份 | 无账号、无昵称，按进入顺序标记为 1️⃣～🔟，每条消息显示来自哪个编号。先发没用过的编号，10 个都用过后再发最早空出的那个，新来的人不会马上顶替刚离开的人；有人进出、掉线、回来时房间里会提示。编号只是座位号，不能证明对方是谁 |
| 网页 | 无外部资源、无统计、无 Cookie；CSP 只允许本站资源，不发送 Referer，禁止被其他网站嵌入；强制 HTTPS（HSTS） |
| 防滥用 | 每个房间最多 10 人，可锁定；每人每 6 秒一条消息（服务器同样检查）；每个连接 10 秒内最多 20 个数据帧；单帧上限 4 KB；阻止其他网页借访客的浏览器连进来（浏览器以外的程序可以伪造来源，所以这不是身份验证）；每个连接连续发 5 个格式错误的数据就断开；锁定 / 解锁每 2 秒最多一次；同一 IP 每分钟进房次数有上限（Cloudflare 边缘内存计数，不记录） |
| 不留痕迹 | 不使用 Cookie、localStorage 等任何浏览器存储；所有页面和脚本都带 `Cache-Control: no-store`，不写入磁盘缓存；打开、切到后台和关闭页面时请求 `/bye`，服务器回 `Clear-Site-Data: "cache", "storage"`（不清 Cookie：Cookie 的清除范围是整个注册域名，会把同域名其他网站的登录一起清掉），浏览器随即清空本站缓存和数据；覆盖 Cloudflare 默认的网络错误上报（`NEL: {"max_age":0}`），浏览器不再保存上报规则；离开时从内存中丢掉暗号、密钥和消息；消息输入框关闭拼写检查（避免增强拼写检查把文字发给第三方） |
| 断线 | 每 25 秒心跳检测，连接无响应或断开都会自动重连。服务器给每个连接一个只在内存里的重连凭证，掉线 2 分钟内回来仍是原来的编号，锁定的房间也能回来；主动离开的人凭证立即作废。断线期间的消息收不到 |

## 做不到的事
- 暗号就是唯一的钥匙。暗号越短、越常见，别人越容易猜中并进入房间、解密消息（短于 8 个字时房间里会提醒）。重要的谈话请用随机生成的暗号。
- 同一个暗号永远对应同一个房间地址和同一把钥匙：能看到房间地址的人（例如服务器运营方）可以离线批量猜测弱暗号；以后知道暗号的人也能解开以前被截获的密文（没有前向保密）；有人离开后钥匙不会更换。
- 知道房间地址的人即使没有暗号，也能占座位、锁房或发送无法解密的垃圾数据（但看不到内容）。
- 服务器看不到内容，但能看到连接的 IP 地址和时间，以及哪些连接在同一个房间（Cloudflare 的网络层面）。需要隐藏 IP 请配合可信的 VPN。
- 网页版加密的代码由服务器下发：部署账号一旦被盗，代码可能被替换。部署账号务必开启两步验证。
- 输入法、剪贴板管理器、手机系统本身都能看到你打的字，这超出网页能保护的范围。不要用带云输入的输入法。
- 浏览器历史记录（包括地址栏输入过的带暗号的网址）网页无权删除，建议用无痕 / 隐私窗口打开。离开时网页会丢掉暗号、钥匙和消息的引用，但无法强制浏览器立即擦除内存。
- 没有验证对方身份的机制（任何知道暗号的人都只是一个编号）。
