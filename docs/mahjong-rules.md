# 麻将·血战入门

四人使用万、筒、条各一至九，每种四张，共108张。庄家14张，其余13张。开局各自选择定缺，定缺仍在手中时必须先打该门牌；含定缺不能胡、碰、杠。不换三张、不允许吃。

支持碰、直杠、暗杠、补杠及抢补杠胡；响应窗口内胡优先于碰杠，多人可同时胡同一张牌。碰杠按从出牌者起的座次优先。胡牌为四组顺子/刻子加一对（已副露组数相应扣除），或门清七对；四张相同牌可视作两对。不计算番型。

胡后退出本手，至三人胡或牌墙耗尽结束。自摸时每位尚未胡的其他玩家付1分；点炮时出牌者向每个胡牌者付1分。当前局累计分数，下一局重新计分。不计杠分、不查叫、不查花猪；本玩法不是完整标准四川麻将计分。

定缺及摸打限时30秒，响应限时12秒。超时定缺选择手中最少的门（平局按万筒条）；超时打出手中第一张定缺牌，若无则第一张手牌；超时响应视为放弃。断线保留座位并执行同样超时规则。

## 客户端协议

牌ID为0至107；牌类`floor(id/4)`，门`floor(牌类/9)`（0万、1筒、2条），点数`牌类%9+1`。每个动作包含`gid`、`revision`、`k`。定缺为`k:suit,suit:0..2`，打牌为`k:discard,card:ID`，回合内杠为`k:kong,card:state.choices中的ID`；响应动作`pong/kong/hu/pass`没有额外字段；结算后`next`开始新局。

服务端快照只含本人手牌、各家张数及公开信息；他人暗杠牌面以null隐藏。服务端持久化快照包含完整牌墙和暗牌，不得直接发往网络。
