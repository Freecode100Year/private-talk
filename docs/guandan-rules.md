# 掼蛋首版采用规则

四人固定座位，隔座搭档，两副含大小王的牌共108张，每人27张。牌ID为0–107；每54张一副，前52张按梅花、方块、红桃、黑桃各13张，点数2至A，末两张为小王、大王。

从2级开始，级牌高于A、低于小王；红桃级牌可替代任意非王牌构成组合，单独打出时仍为级牌。支持单张、对子、三张、三带二、五张顺子、连续三对、连续两组三张、四至十张同点炸弹、五张同花顺、四王炸弹。顺子不含王，级牌在顺子中按印刷点数；A可接在2之前或K之后，不能绕圈。连续对子和三张也允许A在2之前。三带二必须两个不同点数。王牌对子只能由两张相同王构成。

同类同长度普通牌按主点比较；三带二比较三张。任何炸弹大于普通牌；炸弹先比长度再比点数，同花顺大于五张及以下炸弹、小于六张及以上炸弹，四王最大。每次出牌需严格大于上一手。首手不能过牌；其余玩家可过牌。其余仍在打牌的玩家全部过牌后，上一手玩家领出；若其已出完，由尚有牌的搭档接风，否则顺时针下一个有牌者领出。

三人出完后，剩下一人记末游。头游与搭档名次为前两名时升三级；搭档第三升两级，搭档末游升一级。双方分别保存级数，下一副采用胜方级数，最高封顶A。本版为持续牌桌，不另设过A结束整场的规则。分数为各自搭档累计升级数，不作押注或金钱计分。

下一副末游向头游进贡；若胜方包揽前两名，则末游向头游、第三向第二进贡（固定对应，不作双贡大小交换）。进贡方合计持有两张大王则抗贡，头游先出。否则依次进贡最高单牌，红桃级牌免贡；受贡方各还一张10以下含10且非级牌的牌，如没有则还单牌值最低的一张。贡还完成后末游先出。所有贡还牌公开显示。本版不采用其他地方双贡、回贡或轮转变体。

每回合30秒。超时领出最低单牌，有上一手则过牌；贡还按上述合法条件自动选择。离线座位保留，超时继续托管。旁观者不能看到手牌。只有当前行动者能提交带当前局ID和版本号的行动，过期或非法行动不推进状态。
