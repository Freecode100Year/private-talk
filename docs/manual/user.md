# 用户使用手册

给所有使用者：不需要安装任何东西，也不需要账号。手机和电脑上的 Chrome、Edge、Safari、Firefox 都可以用。

下文用 `https://聊天网址` 表示你所用网站的地址，例如 `https://chat.freedom8964.com`，或者管理员给你的内网地址 `https://192.168.1.20:8443`。

## 需要下载什么

**什么都不用下载。** 用手机或电脑上已有的浏览器（Chrome、Edge、Safari、Firefox）打开网址即可。浏览器请保持更新到较新的版本。

## 1. 进入房间

**收到了房间链接**：直接打开，就进入了那个房间。

**自己开一个房间**，有两种方法：

- 打开 `https://聊天网址`，首页已经随机生成了一个暗号（22 个字符，别人不可能猜中），点「进入房间」。不喜欢可以点「换一个」，也可以自己输入暗号。
- 直接在浏览器地址栏输入 `https://聊天网址/#暗号`，回车。

暗号的规则：

- 只能用数字、英文字母、中文（简体或繁体），不能有符号、标点、空格、表情。
- 最短 1 个字，最长 64 个字。英文区分大小写；“龙”和“龍”是两个不同的房间。
- **暗号越短越容易被别人猜中**。只聊几句闲话可以用短暗号，重要的谈话请用随机生成的。

## 2. 邀请别人

点「复制房间链接」，通过可信的渠道发给对方（当面、Signal、加密邮件等）。

- 链接里就是暗号，谁拿到链接谁就能进来。
- 不要用微信、QQ 等会被审查或保存记录的软件发送。
- 发完后清空剪贴板（复制一段无关的文字即可）。

## 3. 聊天

- 每个人有一个编号 1️⃣～🔟，最多 10 人。没有昵称，也看不到别人的身份。
- 每条消息最多 500 字。每人每 6 秒只能发一条，发送按钮会倒数。
- 页面顶部的**房间代号**（4 位字母数字）由暗号算出。和对方核对代号一样，就说明你们在同一个房间、暗号没有打错。
- 进出房间的人会有提示。
- **锁定房间**：人到齐后点「锁定房间」，之后新的人拿到链接也进不来。房间里的人掉线（锁屏、换网络）2 分钟内仍能用原编号回来。任何人都可以解除锁定。
- **消息保留**：可以设成 1 / 5 / 30 分钟后自动从屏幕上删掉。
- **清屏**：点「清屏」或按 Esc，立即清掉屏幕上的消息和输入框。
- 界面语言自动跟随系统（简体、繁体、English），右上角可以切换。

## 4. 离开

点「离开房间」或直接关闭网页。关闭网页时会自动清除本站的缓存和数据。所有人离开后房间消失，消息不会留在任何地方。

## 5. 安全习惯

- **用无痕 / 隐私窗口打开**。地址栏里带暗号的网址会留在浏览器历史里，网页删不掉。
- **不要用带云输入的输入法**（如搜狗、百度的云输入）。它们会把你打的字传到自己的服务器，这超出网页能保护的范围。
- **注意屏幕**：别人能看到你的屏幕，就能看到消息。截图和录屏也无法阻止。
- **核对房间代号**：和对方用另一种方式核对代号，确认没有进错房间。
- **没有身份验证**：房间里的人只有编号。对方是谁，需要你自己通过其他方式确认。

## 6. 内网地址第一次打开时的证书提示

在局域网、企业内网里使用时，浏览器第一次可能提示“您的连接不是私密连接”或“此连接不受信任”。这是因为证书由内网服务器自己签发，不是公网证书机构签发的。

- 确认地址是管理员告诉你的那个，就可以点「高级」→「继续前往」（Safari：「显示详细信息」→「访问此网站」）。连接照样是加密的。
- 管理员给了你一个 `ca.crt` 证书文件时，按[局域网手册](lan.md#5-让设备不再提示证书)安装，以后就不再提示。
- **在互联网上的公开网站**（例如 chat.freedom8964.com）出现证书提示，**不要继续**，那可能是有人在冒充网站。

## 7. 常见问题

| 现象 | 原因和做法 |
| :--- | :--- |
| 提示“房间已满” | 已经有 10 个人，等有人离开 |
| 提示“房间已锁定” | 房间里的人锁定了房间，请他们解除 |
| 提示“暗号只能用数字、英文字母和中文” | 暗号里有符号或空格，去掉它们 |
| 显示“正在重新连接” | 网络断了一下，会自动重连；2 分钟内回来编号不变 |
| 发送按钮在倒数 | 每 6 秒只能发一条，等倒数结束 |
| 对方看到的房间代号和我不一样 | 暗号不一样（大小写、简繁体、多打了字），重新核对链接 |
| 页面提示无法加密 | 网址不是 https 开头，或浏览器太旧。请用 https 地址和新版浏览器 |

更多问题见 [故障排查](troubleshooting.md)。
