# 故障排查

先确认是哪一类问题，再看对应的表。

**管理员先跑两条自检**（输出不含暗号、密钥，可以直接发给帮你排查的人）：

- 离线包 / 局域网：双击 `status.cmd`（或 `./status.sh`）——版本、设置、证书还剩几天、是否在运行。
- 任何部署：在装了 Node.js 22 的电脑上运行 `node server/smoke.mjs https://你的网址`（局域网加 `--insecure`；Docker 部署直接 `./pt status`）——两个测试客户端互发一条加密消息，最后一行是 OK 说明聊天整条路是通的；不是 OK 时，它会说卡在哪一步（证书、连接被关、超时）。

## 打不开网页

| 现象 | 原因 | 做法 |
| :--- | :--- | :--- |
| 浏览器显示“无法访问此网站” | 服务器没运行、地址或端口错、防火墙拦截 | 在服务器本机打开 `https://127.0.0.1:端口/` 确认程序在运行；检查防火墙 |
| 局域网里别人打不开，本机可以 | 防火墙只放行了本机；路由器“AP 隔离 / 访客网络” | 放行端口（专用网络）；关闭 AP 隔离或换到主网络 |
| 证书错误（公网网站） | 证书没申请成功，或者有人冒充 | 管理员检查证书；**用户不要点继续** |
| 证书提示（局域网 / 内网） | 程序自己签发的证书 | 正常，见[局域网手册](lan.md#4-第一次打开的证书提示) |
| Cloudflare 错误 1033 | 隧道没连上 | 检查运行 cloudflared 的设备和令牌 |
| 502 / 504 | 代理连不到程序 | 代理转发地址、端口是否正确；程序是否在运行 |

## 页面能打开，但用不了

| 现象 | 原因 | 做法 |
| :--- | :--- | :--- |
| 红色提示“这个网址不是 HTTPS” | 用了 http:// 地址，浏览器不允许网页加密 | 改用 https:// 地址；管理员要提供 HTTPS |
| “进入房间”后一直“正在连接” | 代理、防火墙或安全网关拦截了 WebSocket | 放行 `/ws/` 的 WebSocket 升级（`Upgrade`、`Connection` 头） |
| 提示“房间已满” | 已有 10 人 | 等人离开，或换一个暗号开新房间 |
| 提示“房间已锁定，进不去” | 房间里的人锁定了房间 | 请他们解除锁定 |
| 提示“进入次数太多，请稍后再试” | 同一 IP 每分钟进房超过 30 次（多人共用出口 IP 时容易遇到） | 稍等一分钟；管理员可调高 `JOIN_LIMIT` |
| 提示“服务器连接数已满” | Node.js 版同时在线连接达到 `MAX_CONNECTIONS`（默认 2000） | 稍后再试；管理员可调高 `MAX_CONNECTIONS` |
| 提示“服务器正在重启” | 管理员在升级或重启 | 页面会自动重连；房间重新开始 |
| 暗号输入报错 | 暗号里有符号、空格或表情 | 只用文字和数字（任何语言） |
| “这个页面版本太旧或暗号不对” | 网站刚更新，旧页面还开着 | 刷新页面重新进入 |
| “锁定房间”按钮是灰的 | 只有房主（👑）能锁定和移出成员 | 请房主操作；房主离开后，最早进入的人自动接任 |
| “你被房主移出了房间” | 房主把你移出了 | 房间没锁时可以重新打开链接进入 |

## 聊天中

| 现象 | 原因 | 做法 |
| :--- | :--- | :--- |
| “正在重新连接” | 网络断了一下、手机锁屏 | 会自动重连；2 分钟内回来编号不变 |
| 掉线超过 2 分钟后进不去 | 房间已锁定，原编号不再保留 | 请房主解除锁定 |
| 重新连接后编号变了、锁定解除了 | 所有人都断开过（例如大家同时锁屏），房间重新开始 | 请房主重新锁定 |
| 收不到别人的消息，提示“来源对不上” | 本机时间和别人相差超过 10 分钟 | 打开系统的“自动设置时间” |
| 对方收不到我的消息 / 编号对不上 | 两人进的不是同一个房间 | 核对页面顶部的房间代号；暗号的大小写、简繁体要完全一样 |
| 发送按钮在倒数 | 每人每 6 秒只能发一条 | 等倒数结束 |
| 消息自己消失了 | 设了“消息保留”时间，或有人按了清屏（只清自己的屏幕） | 正常现象 |
| 服务器重启后房间没了 | 房间只在内存里 | 重新打开链接即可回到同一个（空的）房间 |

## 部署时

| 现象 | 做法 |
| :--- | :--- |
| `npm` 报 Node.js 版本过低 | 需要 Node.js 22 或更新版本；或者改用自带 Node.js 的离线包 |
| 内网装不了依赖 | 用离线安装包，见[企业内网手册](enterprise.md) |
| 端口被占用（EADDRINUSE） | 用 `PORT=其他端口` 启动 |
| Linux 上用 443 端口报权限错误 | 非 root 不能用 1024 以下端口：systemd 里打开 `AmbientCapabilities=CAP_NET_BIND_SERVICE`，或用 8443 |
| 局域网证书里没有我要的名字 | 用 `LAN_NAMES=名字或IP` 启动；只接受内网地址和 `.local`、`.lan`、`.internal`、`.home.arpa` 名字 |

还解决不了：到 <https://github.com/Freecode100Year/private-talk/issues> 提问题，写清楚部署方式、浏览器、出现的提示文字。**不要贴出房间暗号或链接。**
