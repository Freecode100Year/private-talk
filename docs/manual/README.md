## 怎么选

```text
只在同一个网络里用？
├─ 是 → 能上互联网吗？
│        ├─ 能 → 局域网手册（或安卓手机手册）
│        └─ 不能 → 企业内网手册（离线安装包）
└─ 否，要在互联网上用 → 有服务器吗？
         ├─ 没有 → Cloudflare 手册（最省事）或 家用设备手册
         ├─ 有境外 VPS → VPS 手册
         └─ 在用 Tailscale → Tailscale 手册
```

## 所有环境都一样的地方

- **内容只在浏览器里加密和解密**。服务器只转发看不懂的密文，不保存消息、不要账号、不写日志。
- **知道暗号的人都能进房间**。暗号就是钥匙，要通过可信的渠道发送。
- **必须 HTTPS**。浏览器只在 HTTPS 下允许网页加密，每本手册都讲了怎么得到 HTTPS。
- **一个暗号对应一个房间**：所有人离开后房间消失，以后用同一个暗号打开会是一个新的空房间。
