# 隐匿对话 · 交互演示

“和陌生人，只聊这一会儿。”——一个**匿名、临时、不留历史**的私密会话的交互原型。

> ⚠️ 这是**交互演示**：不会建立真实连接、不会发送消息、不使用真实加密。页面上的“对方”和消息都是本地模拟的。

## 演示流程

1. **输入房间暗号**（只能用英文字母和数字），生成私密邀请链接。暗号就是唯一凭据。
2. **把邀请交给对方**：只通过可信渠道分享；链接泄露就重新创建。
3. **匿名对话**：最多 8 人，单条消息最多 500 字；最后一人离开，会话和消息立即销毁。

设计原则：不需要身份 · 不保存历史 · 随时离开。

## 目录

| 路径 | 内容 |
| :--- | :--- |
| `dist/` | 静态网页（HTML / CSS / 原生 JS 模块，无依赖、无外部资源、无统计） |
| `dist/state.js` | 房间与消息规则（暗号校验、邀请码、长度限制） |
| `dist/_headers` | 安全响应头（CSP 只允许本站资源、不发 Referer、禁止被嵌入） |
| `test/` | `state.js` 的单元测试 |
| `wrangler.jsonc` | Cloudflare Workers 静态资源部署配置 |

## 本地运行

```sh
npx serve dist        # 或任意静态服务器
npm test              # node --test，需要 Node 18+
```

## 部署

```sh
npx wrangler deploy
```
