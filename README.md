# 隐匿对话

**和陌生人，只聊这一会儿。** 匿名、临时、端对端加密的私密房间：无需账号，不保存消息，最后一人离开，房间就不存在了。

线上地址：<https://chat.freedom8964.com>

## 怎么用

1. 打开网站，输入一个**房间暗号**（英文字母和数字，至少 8 位），进入房间。
2. 点“复制房间链接”，通过可信渠道发给对方。链接形如 `https://chat.freedom8964.com/#暗号`。
3. 对方打开链接就进入同一个房间。最多 8 人，每条消息最多 500 字 / 2048 字节。
4. 离开时点“离开房间”或直接关掉页面。

## 隐私设计

| | 做法 |
| :--- | :--- |
| 暗号 | 只在浏览器里用。放在链接 `#` 后面，浏览器不会把它发给服务器；进入房间后立即从地址栏抹掉 |
| 房间地址 | 由暗号经 PBKDF2-SHA256（31 万次）算出的 64 位十六进制，服务器无法反推暗号 |
| 消息 | 浏览器用暗号派生的 AES-256-GCM 密钥加密；服务器只转发密文，没有密钥 |
| 历史 | 不存储。服务器（Cloudflare Durable Object）只在内存里转发；新加入的人看不到之前的消息 |
| 身份 | 无账号、无昵称，按进入顺序显示为“访客 1、访客 2…” |
| 网页 | 无外部资源、无统计、无 Cookie；CSP 只允许本站资源，不发送 Referer，禁止被其他网站嵌入 |
| 防滥用 | 每个房间最多 8 人；每个连接 10 秒内最多 20 条；单帧上限 4 KB；只接受本站页面发起的连接 |

**要知道的限制**：
- 暗号就是唯一的钥匙。暗号太短或太常见，别人可能猜中并进入房间、解密消息。用长一点、不常见的暗号。
- 服务器看不到内容，但能看到连接的 IP 地址和时间（Cloudflare 的网络层面）。需要隐藏 IP 请配合可信的 VPN。
- 这是轻量工具，没有验证对方身份的机制（任何知道暗号的人都是“访客”）。

## 目录

| 路径 | 内容 |
| :--- | :--- |
| `dist/` | 网页：`index.html`、`app.js`（界面与连接）、`crypto.js`（密钥派生与加解密）、`state.js`（暗号与消息规则）、`_headers`（安全响应头） |
| `src/worker.js` | Cloudflare Worker：静态资源 + `/ws/<房间>` WebSocket 转发（每个房间一个 Durable Object，不存储任何内容） |
| `test/` | 规则与加密的单元测试 |
| `wrangler.jsonc` | 部署配置（自定义域名 chat.freedom8964.com） |

## 开发

```sh
npm test               # Node 18+
npx wrangler dev       # 本地运行（含 WebSocket 转发）
npx wrangler deploy    # 部署
```
