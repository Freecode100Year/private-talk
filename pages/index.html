Core Principles

四个核心特点

没有账号体系，没有多余负担。把通讯的控制权彻底交还给你。

🛡️

隐匿

不要账号、不要手机号、不要昵称。消息在浏览器里加密，服务器只转发看不懂的密文，不保存消息，程序不写日志。

⚡

简单

打开网址、输入暗号，就在同一个房间。不用装 App，手机电脑都能用。聊完关掉网页就走。

不审查

没有敏感词过滤、没有内容审核、没有举报和封号，也没有后门。服务器看不懂消息，也不按内容做任何判断；限制只有人数、发送频率和长度，用来防止被刷爆。

随处可部署

Quick Start

30 秒上手

三步开启私密对话，随时随地，即用即走。

1

输入暗号进入房间

在浏览器打开 https://chat.freedom8964.com/#你们的暗号。如果直接打开首页，会为你自动生成一个无法猜中的长随机暗号。

2

把网址发给朋友

把包含暗号的链接发给朋友，或者告诉他们你们约定的暗号。邀请链接永不过期，暗号进入房间后会从地址栏抹除。

3

进房畅聊，聊完即走

打开同一个网址的人进入同一个房间（最多 25 人）。最早进房者是房主，人齐后可锁定房间。聊完关掉网页，房间彻底消失。

暗号使用提示：暗号可以用任何语言的文字和数字，不要符号。暗号越长越安全。详见 用户使用手册。
Privacy & Security

谁能看到什么

透明坦诚的技术设计：每一层网络与角色能够看到什么、绝对看不到什么。

谁 能看到 看不到
服务器运营方 你的 IP、上线时间、哪些连接在同一个房间 消息内容、暗号、你是谁
网络旁观者
（运营商、Wi-Fi 管理者）		 你连了这个网站 内容、暗号、房间
房间里的人 消息，以及你的临时编号（1️⃣～🔟，之后 #11～#25） 你是谁、你的真实 IP

🔐 严格的加密与安全保证

端对端加密：密钥由暗号在浏览器本地算出（PBKDF2 31 万次 → HKDF → AES-256-GCM）；消息补齐到固定几档长度，密文看不出一句话字数。

前向保密与后量子安全：每人进房生成临时密钥，每条消息一把一次性钥匙，有人离开全体换钥匙；叠加抗量子的 ML-KEM-768（防「现在录下、以后用量子计算机解」）；每条消息带签名，别人冒用不了你的编号；侧栏显示 20 位安全码供核对。

不留存、不留痕：没有账号、没有消息历史，程序不写日志。所有人离开后房间消失；不用 Cookie 和本地存储，页面禁止缓存，关闭时让浏览器清除本站数据。

🛡️ 防篡改与安全设计

安全发图片：在浏览器里压缩并自动抹去拍摄地点（GPS）等 EXIF 隐私，用一次性密钥加密随前向保密通道传输，服务器只见密文。

防篡改与房主权限：发送人、时间、消息编号封在密文里，服务器无法改动；最早进入的人是房主，人到齐后可锁定房间、移出成员；房主离开由下一位自动接任。

没有暗号进不来：服务器只认由暗号算出的进入凭证，只知道房间地址的人不能占座、锁房或发消息。暗号写在 # 后面，浏览器绝不会发给服务器。

⚠️ 做不到的（请务必知道，不夸大保护能力）

  • 知道暗号的人都能进来，也能听到以后的对话。暗号越短越容易被猜中，重要的谈话请务必使用无法猜中的长随机暗号。邀请链接不会过期。房间里有旧版本的成员时会退回没有前向保密的旧方式（页面会提示）。
  • 服务器能看到 IP。要隐藏 IP 地址，请配合可信的 VPN 或 Tor 代理使用。
  • 不能证明房间里的人是谁；对方可以截图、拍照或复制；输入法记录、被木马监控的设备超出网页能保护的范围。「清屏」只清你自己的屏幕。
  • 网页代码由服务器下发：部署者账号若被盗，代码可能被替换。可以用签名清单核对，但只针对某一个人的替换核对不出来；最稳妥是用安卓 App 或离线包。
完整机制请参阅开源文档：隐私与安全设计文档 (docs/privacy.md)。

Cryptographic Verification

完整性校验

任何人都可以核对线上网页与发布包未被运营商或中间人劫持修改。

🔍 网页签名清单校验

网站附带签名的文件清单（dist/integrity.json），任何人都能使用项目开源核对脚本比对正在运行的线上网页代码，确认每一个文件与发布时完全一致： 

node scripts/verify-site.mjs https://chat.freedom8964.com

详见源码：scripts/verify-site.mjs。

✍️ 发布包签名与哈希校验

每次发布的离线包和 Docker 包都附带 SHA-256 校验值和发布密钥的签名（公钥是 server/release-key.pem），更新程序签名不对就拒绝安装；安卓 APK 的校验值写在各自的发布页。
